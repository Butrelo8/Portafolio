RESA Privacy Policy

Last updated: October 7, 2026

1. What RESA is

RESA is a personal command-line tool operated by Bernardo Ivan Aguirre Vargas (Veracruz, Mexico). It has one user: its author. It has no accounts, no sign-in, and no hosted service.

2. Use of YouTube API Services

RESA uses YouTube API Services to search public videos and read public video and channel statistics (titles, descriptions, view counts, like counts, duration, publish dates, subscriber counts). By using RESA you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data collected

RESA collects only public metadata returned by YouTube API Services and other public web sources. It does not collect, store, or process any personal data of users, viewers, or commenters. It never requests Google account authorization (OAuth); it uses an API key only. It does not access private, unlisted, or authorized data of any kind.

4. Storage and retention

Collected API data is stored locally on the author's computer in JSON files and a local SQLite database. YouTube API data is refreshed on each query and is not retained beyond 30 days; records older than 30 days are discarded. No data is stored on third-party servers.

5. Sharing

API data is not shared with, sold to, or disclosed to any third party. It is not displayed on any public website or combined with external data sources for commercial purposes.

6. Cookies and tracking

RESA does not use cookies, analytics, advertising, or any tracking technology.

7. Deletion and revocation

Stored data can be deleted at any time by removing the local data directory. Since RESA never obtains user authorization, there is nothing to revoke; a Google user's permissions can always be managed at Google security settings.
