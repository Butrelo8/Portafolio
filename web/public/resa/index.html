RESA

RESA is a personal, single-user command-line tool for research. It collects public metadata about web pages and social media posts (titles, descriptions, view counts, publish dates) and stores it locally on the owner's computer as JSON files.

YouTube

RESA uses YouTube API Services to search public videos by topic and region and to read public statistics of videos and channels. It does not upload, modify, comment, or access any private account data. It uses an API key only; no user ever signs in with a Google account.

Who uses it

Only its author. RESA is not distributed, sold, or offered as a service. There is no sign-up and no login.
